# Estudiá Ciencia — Estudiá en el Obser

Primera V1 de la landing del proyecto de extensión.

## Local
npm install
npm run dev

Abrir http://localhost:3000

## GitHub + Vercel
1. Crear un repositorio nuevo en GitHub.
2. Subir estos archivos.
3. En Vercel: New Project → Import Git Repository.
4. Vercel detecta Next.js y publica automáticamente.
